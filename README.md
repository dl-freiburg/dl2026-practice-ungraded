# Deep Learning exercises: practice copies (not graded)

The starter code of every released exercise, for practising, e.g. for the exam. Nothing here is graded and nobody gets feedback: this is not a submission. To work on an exercise for points, register a team as described on the first exercise sheet and work in your team's repository.

Clone once, then `git pull` after each release for the next exercise. Each folder has the sheet (PDF), the code and the tests; `python scripts/grade.py` inside a folder runs the tests like the grading does.

**Keep your solutions to yourself.** Do not fork this repository and do not push your work to a public repository: a fork of a public repository is public, and so is everything you push there. Work in your clone (pushing to this repository is not possible), and if you want your work on GitHub, put it in a private repository. Once you have a team, copy your work into your team's repository.
